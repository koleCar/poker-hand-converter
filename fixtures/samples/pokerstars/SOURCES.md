## Verification methodology

Every file in this directory was re-checked on 2026-09-17 for two structural self-consistency properties that a real, unaltered PokerStars export must satisfy and that a doctored or forum-transcribed one often does not:

1. **Seat-block/action-line name agreement** — every player name that appears in an action line (`X: folds`, `X: posts ...`, etc.) must also appear verbatim in a `Seat N: X (...)` line from the same hand's header, unless the player is independently documented as a genuine late-joiner with no printed seat line (this is real, attested PokerStars behavior — see files 07's `hiphoppanda` and 12's `Valorian`, both `is sitting out`/`leaves`/cancelled-before-dealt players who never got a seat line). Checked programmatically across all 45 remaining files; the only true mismatch found was file 18 (removed, see above).
2. **Uncalled-bet arithmetic** — when a raise or bet on the last aggressive action goes uncalled (everyone left folds), a real raw export always prints `Uncalled bet ($X) returned to <player>` before that player's `collected` line. Files 07 and 08 are missing this line despite the surrounding pot totals being arithmetically consistent with it having happened — see their TRANSCRIBED (lossy) status above. This was a manual spot-check prompted by peer review, not (yet) run exhaustively over every file in the directory; treat any other file's uncalled-bet lines as unverified until independently checked.

This methodology check is not exhaustive (it does not re-derive full pot/rake arithmetic for every street of every file), so a future contributor finding a further inconsistency should fix the label rather than assume everything not flagged here has been proven clean.

## Known gaps (explicitly not covered by any fixture above)

- **Spin & Go** (3-max hyper-turbo jackpot SNG). No real sample found in any corpus searched (HHSmithy is pre-Spin&Go; the fpdb corpus predates Spin&Go's ~2015 launch). Every "Spin & Go hand history" found on GitHub during research was itself a fabricated/synthetic fixture from another developer's project (sequential fake hand IDs, dates in the future) — none were used here. This remains an open gap; do not assume Spin&Go's header differs from a normal 3-max tournament header without a real sample.
- **HORSE / full mixed-game rotation summary** beyond the single per-hand `Mixed Hold'em (Hold'em Limit)` header shape in file 39. We have one leg of a mixed rotation, not a rotation schedule.
- **Localized (non-English) PokerStars client output.** Searched for and did not find one — see the note above about the removed file 47. Any claim in the doc about localized output is a secondary-source inference, not fixture-backed.
- **Tournament run-it-twice** and **tournament rabbit-hunting** — the cash run-it-twice fixtures (03, 29) are real, but no tournament hand combining run-it-twice with a `Tournament #` header was found.
- **Tournament final-table `wins the tournament and receives $X`** line (as opposed to `finished the tournament in Nth place`) — not present verbatim in any fixture here; every tournament file we found real samples for ends before or without reaching 1st place. Treat this exact phrasing as a secondary-source claim in the doc until a real 1st-place-finish hand is found.
