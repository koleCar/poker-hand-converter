# iPoker network (Playtech) — sample sources

All files below are byte-exact copies (`cp`, UTF-8 with BOM as checked out) from the
[HHSmithy/PokerHandHistoryParser](https://github.com/HHSmithy/PokerHandHistoryParser) unit-test corpus,
under `HandHistories.Parser.UnitTests/SampleHandHistories/IPoker/CashGame/`, retrieved 2026-09-16.
Era: ~2012–2014 (real-money cash games only; no tournament sample exists in this corpus — see
docs/research/hh-formats/ipoker.md for the tournament-format gap). Files are given a `.xml` extension
here because their content genuinely is XML, even though the upstream repo used `.txt`. No file has been
retyped, reformatted, or had its bytes altered — this matters more than usual for this network since two
of the kept files exist specifically to demonstrate real whitespace/structural variation.
